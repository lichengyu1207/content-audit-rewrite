# content-audit-rewrite · 内容审核与原创改造 Skill

一套经过实战检验的内容工作方法论，固化为可复用的 AI Agent Skill。把「审核原创性 → 识别限流风险 → 观点化改造 → 风格统一」变成标准流程。

## 它解决什么问题

写内容时反复遇到的四件事：

1. **这篇文章是不是我自己的？** —— 判定拼凑、洗稿、AI 套话，给出原创性等级
2. **会不会被限流？** —— 预判公众号 / 知乎 / 小红书 / 抖音 / 朋友圈的审核红线，敏感词逐条替换
3. **怎么改成观点文？** —— 把资讯、感悟、故事改造成有立场、有判断、有认知框架的内容
4. **风格怎么不散？** —— 保持冷峻、锋利、有格局感的统一表达

## 三种典型用法

**① 审核已有内容**

> "按这个标准审一下这篇文章：……"
>
> → 输出原创性等级、三级风险清单、修改逻辑表、完整改后版本

**② 改写降险 / 观点化改造**

> "把这段改成观点文，避开限流词"
>
> → 保留观点骨架，替换风险皮肉，六条替换法自动执行

**③ 创作新内容**

> "帮我写一篇公众号，观点是：你以为的努力其实是逃避"
>
> → 场景→问题→拆解→反转→收束，写完自动跑发布前自检

## 方法论内核

- **核心原则**：保留骨架，替换皮肉
- **六条替换法**：去宗教化 / 去医学化 / 去政治化 / 去攻击性 / 去绝对化 / 去引流
- **三级风险**：🔴 极高危（删除或重写）｜⚠️ 高危（必须替换）｜⚡ 中危（微调）
- **交付标准**：原创性 ≥ 高 · 限流风险 ≤ 低 · 观点性 ≥ 强 · 风格统一
